# Source and license notice

The modules under `swinir/` are an independent, modular reimplementation of
the SwinIR architecture described in:

> Jingyun Liang et al., "SwinIR: Image Restoration Using Swin Transformer,"
> ICCV Workshops, 2021.

Implementation details and compatibility names were checked against the
official Apache-2.0 implementation:

- <https://github.com/JingyunLiang/SwinIR>
- pinned commit `6545850fbf8df298df73d81f3e8cba638787c8bd`

Unmodified upstream reference files and the upstream license are stored in
`references/`. They are development-time comparison material and are not
imported by the project model at runtime.
