# 重聚焦任务决策索引

> 更新日期：2026-08-18
> 状态：两条路线并行验证，尚未选定最终产品路线

## 1. 为什么保留两种任务认知

`echo_4` 与 `image_4` 的多样本可视化确认了以下事实：

- Echo 是具有场景轮廓的粗成像/散焦复数图像；
- Image 是经过 PFA 重采样及后续处理得到的聚焦复数图像；
- 两者的粗粒度场景结构对应，但聚焦前后的能量分布、峰值、局部几何和复数像素差异很大；
- 8 个代表样本的 Image/Echo RMS 比为 `0.88～1.11`，峰值比为 `1.59～12.77`；
- 当前 patch-only SwinIR 可以过拟合单样本，但 16 对样本联合训练稳定停在 `12/16`；
- 全样本梯度累积和全局行列坐标条件化均未消除剩余冲突。

这些证据支持两种都合理、但目标不同的研究路线：

1. **物理引导 SAR 重聚焦**：显式建模 PFA 几何、二维相位误差和重采样；
2. **通用图像恢复**：有意忽略 SAR 机理，把 Echo/Image 当作模糊/清晰配对图像。

## 3. 两条路线的边界

| 项目 | D001：物理引导 SAR | D002：通用图像恢复 |
| --- | --- | --- |
| 核心问题 | 估计并补偿二维相位/几何误差 | 从模糊图像回归清晰图像 |
| 输入语义 | 粗成像复数 SAR + 场景条件 | 配对的低质量图像 |
| 输出语义 | 物理一致的聚焦复数 SAR | 视觉和结构更接近标签的图像 |
| 主要上下文 | 完整场景或大范围上下文 | patch 或多尺度上下文 |
| 首选模型 | 全局校正估计器 + 可微物理算子 + 局部修复 | SwinIR/多尺度恢复网络 |
| 主要指标 | 复数相干性、相位、点目标、熵、PSLR/ISLR | PSNR、SSIM、幅度相关、边缘和视觉质量 |
| 可作出的结论 | SAR 重聚焦/自聚焦能力 | 数据集内图像恢复能力 |
| 主要风险 | 物理模型或元数据不完整 | 幻觉、场景泄漏、无法解释物理过程 |

## 4. 共享但不可混淆的内容

两条路线共享：

- MAT 数据读取和复数双通道表示；
- Echo 派生的归一化尺度；
- parent scene 身份和按场景划分的 train/validation/test；
- identity、zero、固定复数增益等基线；
- RMSE、幅度相关、PSNR、SSIM 和可视化工具；
- 单样本与小样本过拟合诊断。

以下结论不得跨路线直接复用：

- D002 的高 SSIM 不自动证明相位正确或物理聚焦正确；
- D001 的物理一致性不自动保证人眼视觉质量最佳；
- 同一大图的重叠 patch 不能当作独立场景证明泛化；
- 为可视化分别归一化 Echo/Image 的结果不能作为训练归一化依据。

## 5. 当前项目执行原则

1. 冻结当前 patch-only SwinIR 结果作为共同基线；
2. 新实验必须在报告中声明属于 D001、D002，或明确的桥接实验；
3. 两条路线使用相同的场景隔离测试集合，方便公平比较；
4. 在获得多场景测试证据前，只报告“场景内拟合”，不报告泛化；
5. 任何最终方案必须说明是否恢复复数相位、是否依赖成像元数据，以及推理时需要多大上下文。
