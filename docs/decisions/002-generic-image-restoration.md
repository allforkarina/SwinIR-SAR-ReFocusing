# D002：将 Echo→Image 作为通用配对图像恢复

> 日期：2026-08-18
> 状态：接受，作为独立数据驱动路线并行验证
> 决策所有者：项目组
> 影响范围：任务命名、数据表示、模型选择、损失和评价

## 1. 决策

建立一条有意忽略 SAR 成像过程的实验路线：

- 把 Echo 视为模糊、低对比度、能量扩散的输入图像；
- 把 Image 视为清晰、边缘和强响应更集中的目标图像；
- 把任务定义为有监督、同尺寸、配对的图像恢复；
- 允许使用 SwinIR、多尺度 U-Net 或其他通用恢复网络；
- 只根据配对数据和图像指标验证经验映射，不要求模型解释 PFA 或相位误差。

该路线可行，并且适合作为：

- 纯数据驱动上限探索；
- 与物理引导路线的统一基线；
- 快速验证数据是否包含足够可学习的视觉对应；
- 物理校正后局部恢复模块的预训练来源。

但除非额外通过复数和物理一致性测试，其成果应称为“Echo→Image 配对图像恢复”，不能直接等同于完整 SAR 自聚焦。

## 2. 为什么该任务成立

多样本可视化已经确认：

- 每一对 Echo/Image 都能找到对应的粗场景轮廓；
- Echo 中的道路、田块、条带或亮区在 Image 中具有对应位置；
- Image 通常具有更暗背景、更集中峰值和更锐利边缘；
- 这种关系在多个坐标和不同场景内容上重复出现。

因此，即使不解释产生原因，数据仍然满足通用监督恢复最基本的条件：输入包含与目标相关的可见结构，目标代表一种更清晰的图像状态。

## 3. 该路线明确忽略什么

本路线暂不回答：

- 散焦由哪一种相位误差产生；
- PFA 的极坐标重采样如何作用；
- 输出复数相位是否物理正确；
- 网络是否等价于某种成像算子；
- 模型在不同传感器、轨迹或成像模式上是否可迁移。

忽略这些问题是实验边界，不代表它们不重要。

## 4. 两级任务定义

### B1：复数双通道图像恢复

```text
Echo complex
→ [real, imag]
→ restoration network
→ [real, imag]
→ Image complex
```

这是与现有工程最兼容的主任务。它仍然使用复数数据，但把实部/虚部仅当作两个相关图像通道，不向网络提供 SAR 物理模型。

优点：

- 可以恢复完整复数标签；
- 与现有 Dataset、checkpoint 和指标兼容；
- 可与 D001 使用相同测试集合。

风险：

- 不同样本的相位关系可能冲突；
- 局部网络可能缺少恢复长距离拖尾所需的上下文；
- 逐复数像素损失可能再次产生低能量解。

### B2：对数幅度图像恢复

```text
Echo complex
→ log magnitude
→ restoration network
→ focused log magnitude
```

该任务只追求可视化幅度和结构，不恢复目标相位。它用于验证“模糊到清晰”的纯图像处理假设，不替代复数聚焦任务。

优点：

- 目标更接近通用去模糊和增强问题；
- 避免复数相位冲突掩盖结构学习能力；
- 便于使用成熟的 PSNR、SSIM、边缘和感知评价。

风险：

- 无法恢复复数 SAR 数据；
- 可能生成视觉合理但物理错误的强散射点；
- 幅度结果不能用于要求相干处理的下游任务。

执行顺序采用 B2 作为快速可学习性验证，B1 作为更严格的黑盒复数恢复任务。

## 5. 归一化契约

训练时不得像可视化那样分别使用 Echo 和 Image 各自峰值归一化，因为：

- Image 峰值在推理时不可用；
- 会抹掉聚焦前后真实的峰值集中关系；
- 可能形成标签信息泄漏。

允许的训练归一化：

1. 使用 Echo RMS 同时缩放 Echo 与 Image；
2. 使用只从训练集估计的固定全局尺度；
3. B2 中使用由 Echo 尺度定义的对数幅度，再用训练集固定均值/方差标准化。

所有验证和推理必须复用训练阶段冻结的规则。

## 6. 数据划分与采样

通用图像任务也必须遵守 parent scene 隔离：

- 同一完整大图产生的重叠 patch 只能属于一个 split；
- `_2` 场景的 16675 个 patch 不能被解释为 16675 个独立场景；
- 相邻 patch 高度重叠，训练采样应去重或控制有效间隔；
- 验证和测试优先使用不重叠 patch；
- 必须报告 scene ID、patch 坐标和相邻关系。

只在单一场景 `_2` 上训练时，实验结论必须标记为“场景内图像恢复”。

## 7. 模型策略

### 第一基线：当前 SwinIR

保留当前双通道 SwinIR 和复数 Charbonnier 结果，不再重复证明已知的 `12/16` 平台。

### 第二基线：幅度 SwinIR

使用单通道或幅度特征输入，预测聚焦对数幅度。该实验回答：排除复杂相位后，现有 SwinIR 能否统一学习多个样本的结构锐化。

### 推荐模型：多尺度大上下文恢复

图像中的拖尾跨度明显大于 8×8 窗口，且不同位置方向不同。因此推荐采用：

- 编码器—解码器或多尺度 Transformer；
- 更大输入上下文，例如大 patch 输入、中心区域监督；
- 局部高分辨率分支与低分辨率全局分支；
- 必要时加入显式可学习形变/对齐模块。

SwinIR 可以作为局部高分辨率分支，但不强制作为唯一主干。

## 8. 损失设计

### B1 复数恢复

候选组合：

$$
L_{B1}
=
L_{complex}
+\lambda_m L_{log\ magnitude}
+\lambda_g L_{gradient}.
$$

- `L_complex` 保持复数值约束；
- `L_log magnitude` 防止只优化背景而忽略结构；
- `L_gradient` 强化道路、边界和强散射结构。

### B2 幅度恢复

候选组合：

$$
L_{B2}
=
L_1
+\lambda_s(1-SSIM)
+\lambda_g L_{gradient}.
$$

第一轮消融只逐项增加损失，不同时引入大量权重。每个新增项必须证明对独立验证场景有效。

## 9. 评价和基线

必须比较：

- 直接输出 Echo；
- 全零或常数输出；
- 最优固定增益 Echo；
- 简单锐化或传统反卷积基线；
- 当前复数 SwinIR；
- 幅度恢复模型；
- 多尺度恢复模型。

评价至少包含：

- 对数幅度 PSNR 和 SSIM；
- 幅度相关性；
- 输出/标签 RMS、峰值和动态范围；
- 边缘或梯度一致性；
- 主要轮廓和强响应位置的可视化；
- B1 额外报告复数 RMSE 与 coherence。

不得只用锐度、熵或视觉观感判断成功，因为过度锐化和噪声也可能提高这些指标。

## 10. 分阶段实验

### 阶段 B0：确认场景和配对

- 为全部数据建立 parent scene ID；
- 固定场景隔离 split；
- 检查方向、坐标和重叠关系。

### 阶段 B1：幅度可学习性

- 在 1、4、16 对样本上测试幅度模型；
- 与复数 SwinIR 使用相同样本；
- 检查 16 对是否仍出现互相干扰。

若幅度模型可以 16/16，而复数模型不能，说明主要冲突来自复数相位或复数目标设计。

### 阶段 B2：上下文消融

比较：

- `512→512`；
- 更大输入、中心 `512` 输出；
- 多尺度全局—局部模型。

若大上下文明显改善，说明当前 patch 信息或有效感受野不足。

### 阶段 B3：多场景训练

在 scene-disjoint 测试集上比较模型和传统基线。只有该阶段可以讨论泛化。

## 11. 成功标准

通用图像恢复路线成功至少需要：

1. 在未见过的 parent scene 上稳定优于 Echo identity 和传统基线；
2. 输出 RMS 和动态范围无系统性塌缩；
3. PSNR、SSIM、相关性和边缘指标同时改善；
4. 主要轮廓位置正确，不依赖生成不存在的结构获得高锐度；
5. B1 的复数指标不能明显恶化；
6. 对空场景、弱目标和高动态场景分别报告结果。

## 12. 失败解释

- B2 成功、B1 失败：幅度映射可学，但相位目标存在冲突或不可由局部输入确定；
- 大上下文成功、512 patch 失败：上下文不足是主要瓶颈；
- 场景内成功、跨场景失败：模型记住了场景或退化分布；
- 视觉改善、复数指标恶化：只能作为图像增强，不能宣称完整聚焦；
- 所有通用模型均失败：应回到 D001 的物理参数化路线和数据生成链。

## 13. 与 D001 的协同关系

- B2 可以快速提供“结构是否可学”的上限证据；
- B1 可以作为 D001 物理模块后的残差网络；
- D001 输出的校正中间图像可以成为 D002 更容易的输入；
- D002 的视觉损失和评价可用于 D001 的局部质量分支；
- 两条路线必须使用相同 scene split，但结论分别报告。

## 14. 最终表述约束

在没有复数与物理一致性证据时，D002 的成果应表述为：

> 模型学习了从 Capella 粗成像配对数据到 PFA 图像幅度/复数标签的经验恢复映射。

不得仅凭清晰度、PSNR 或 SSIM 将其表述为已恢复真实 SAR 相位、运动误差或 PFA 成像过程。
