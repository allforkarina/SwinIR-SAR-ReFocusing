# D001：物理引导的复数 SAR 重聚焦

> 日期：2026-08-18
> 状态：接受，进入独立实验路线
> 决策所有者：项目组
> 影响范围：数据生成、模型架构、训练目标、评价体系

## 1. 决策

不再把“512×512 局部 Echo patch 经纯 SwinIR 直接回归 Image patch”作为 SAR 重聚焦主方案。

主方案改为：

1. 从完整场景或大范围上下文估计平滑、低维的二维相位和几何校正量；
2. 在 FFT/PFA 相关域中执行显式相位补偿和可微重采样；
3. 使用轻量复数 SwinIR 或其他局部网络修复物理校正后的残余伪影；
4. 最终同时评价复数一致性、聚焦质量和图像结构。

现有 SwinIR 不删除，保留为：

- patch-only 数据驱动基线；
- 物理校正后的局部残差模块；
- 消融实验中的对照组。

## 2. 已确认的数据生成关系

根据 `capellaPFA(1).m`：

```matlab
tmpimg = myfft(hrrp,1);
in_echo = myfft(hrrp,2);
[S_afterAzium, ...] = ext_PFA_8_Bistatic(..., in_echo, ...);
img_PFA_platComp = myfft(myifft(S_afterAzium,2),1);
tmp = flip(img_PFA_platComp,1);

img1 = tmp;      % 最终成像结果
img2 = tmpimg;   % 粗成像结果
```

随后：

- `img2` 被切片保存到 `echo_4`；
- `img1` 被切片保存到 `image_4`。

因此，当前 Echo 应解释为粗成像/散焦复数图像，而不是刚接收的原始回波；Image 是经过 PFA 重采样和后续变换得到的聚焦结果。

## 3. 实验证据

### 3.1 可视化与数值

8 个代表样本均可在 Echo/Image 中找到对应的粗场景轮廓，但 Echo 表现为方向和程度不同的能量扩散，Image 中边缘与强散射点更加集中。

统计范围：

| 指标 | 范围 |
| --- | ---: |
| Image/Echo RMS 比 | 0.88～1.11 |
| Image/Echo 峰值比 | 1.59～12.77 |
| 独立归一化对数幅度相关 | -0.02～0.32 |
| 独立归一化平均绝对差异 | 0.16～0.40 |

整体能量近似，但聚焦后的峰值集中程度和局部结构变化很大。因此不能用统一亮度增益或固定局部模糊核描述全部样本。

### 3.2 训练诊断

- 单个样本可以被 SwinIR 成功过拟合；
- 16 对样本联合训练不能同时通过；
- 4 个失败样本分别训练时均可通过；
- 全样本梯度累积稳定停在 `12/16`；
- 全局 row/col 条件化训练到 2000 epoch 后仍为 `12/16`。

这表明实现和基本容量并非唯一问题。更符合证据的解释是：不同 patch 需要不同的场景级校正，局部输入中缺少决定聚焦算子的条件。

## 4. 核心假设

把聚焦过程抽象为：

$$
I_{focused}
=
\mathcal{R}
\left(
\mathcal{F}^{-1}
\left[
\mathcal{W}_{\Delta k}
\left(\mathcal{F}(I_{coarse})\right)
e^{j\phi(k_x,k_y)}
\right]
\right),
$$

其中：

- $\phi(k_x,k_y)$ 是平滑二维相位校正场；
- $\Delta k$ 是重采样坐标或残余距离迁移修正；
- $\mathcal{W}$ 是可微重采样；
- $\mathcal{R}$ 是物理校正后的局部残差修复。

可检验假设为：

1. 聚焦变换包含场景级、空间变化的二维相位或几何分量；
2. 该分量可以用少量平滑系数表示，而不需要逐像素自由预测；
3. 物理校正完成后，剩余误差更接近 SwinIR 擅长的局部恢复问题。

## 5. 目标架构

```text
完整粗图像或大上下文复数图像
                ↓
全局低分辨率条件编码器
                ↓
平滑相位场 φ + 重采样场 Δk
                ↓
FFT → 相位补偿/可微重采样 → IFFT
                ↓
轻量复数局部恢复网络
                ↓
聚焦复数图像
```

全局编码器不直接生成最终高分辨率图像，而只预测受约束的校正参数，降低幻觉和样本冲突风险。

## 6. 数据契约

每个完整场景至少记录：

- `scene_id`；
- 粗成像复数数据 `tmpimg`；
- PFA 聚焦复数标签 `img_PFA_platComp/tmp`；
- PFA 重采样前后中间量；
- `in_KR`、`in_Ux0`、`in_Uy0` 或等价几何信息；
- 输出坐标、方向、flip/shift 和归一化约定；
- 由该场景产生的所有 patch 坐标。

数据划分必须按 `scene_id` 进行。同一大图的任何重叠 patch 不得跨 train、validation 和 test。

若完整图像过大，可以保存大上下文输入并只对中心区域计算损失，但必须记录上下文尺寸与有效输出区域。

## 7. 分阶段实验

### 阶段 A：算子审计，不训练大模型

对代表样本和完整场景计算：

- 多尺度幅度相关性；
- 最佳平移、仿射或低阶几何配准；
- 最优复数增益；
- Echo/Image 频谱幅度比和相位差；
- 相位差的低阶多项式、B-spline 或其他平滑模型拟合误差；
- 仅相位补偿、仅重采样、相位加重采样的独立贡献。

输出必须回答：任务是相位主导、几何重采样主导，还是二者缺一不可。

### 阶段 B：16 对样本消融

在相同样本和相同评价下比较：

1. 当前 `512→512` SwinIR；
2. 大上下文输入、中心区域输出；
3. 相位校正模块；
4. 相位加重采样模块；
5. 物理模块加轻量 SwinIR。

### 阶段 C：跨场景训练

只有在获得多个 parent scene 后才进入正式训练。报告必须同时包含场景内和场景外表现。

## 8. 损失和评价原则

训练归一化继续使用 Echo 派生的尺度同时归一化输入和标签。不得使用 Image 独有的峰值作为推理所需的归一化条件。

候选训练目标包括：

- 复数 Charbonnier 或复数 L1；
- 对数幅度结构损失；
- 频域复数一致性；
- 相位/重采样场平滑正则；
- 强散射点或边缘的适度加权。

评价至少包括：

- 复数 RMSE 与 coherence；
- 幅度相关、PSNR 和 SSIM；
- 输出/标签 RMS 和峰值比；
- 图像熵、对比度和锐度；
- 有条件时的主瓣宽度、PSLR 和 ISLR；
- 对完整场景拼接边界和几何一致性的检查。

## 9. 成功与停止条件

路线继续的最低条件：

1. 物理参数化模型在同等训练预算下稳定优于 patch-only SwinIR；
2. 改善同时出现在复数、幅度和聚焦指标，而非单一损失；
3. 输出不存在能量塌缩；
4. 在未参与训练的 parent scene 上仍保持改善；
5. 校正参数保持平滑、有限且可解释。

若低维相位和重采样模型无法解释 Echo/Image 差异，应回到 PFA 中间量和数据坐标约定，而不是继续增加网络自由度。

## 10. 风险

- 当前主要样本来自单一场景 `_2`，不足以验证泛化；
- PFA 变换可能包含当前记录之外的方向、坐标和插值约定；
- 只从局部 patch 估计全局相位可能不可识别；
- 过于自由的二维位移场可能把生成式几何变形误当作聚焦；
- 若推理阶段已有完整 PFA 元数据，直接使用确定性 PFA 可能比学习替代更合理。
