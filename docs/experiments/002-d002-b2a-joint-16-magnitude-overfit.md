# E002：D002-B2-A 16 样本联合对数幅度过拟合

> 日期：2026-08-18
>
> 状态：64000步未通过但仍持续改善；后续E003扩预算后通过
>
> 前置实验：[E001 单样本对数幅度过拟合](001-d002-b2a-single-magnitude-overfit.md)

## 已确认的前置证据

E001 的 raw 模型在 step 3600、3700、3800 连续三次通过。最终 normalized log RMSE 为 `0.0742`，相关性为 `0.9928`，幅度 RMS ratio 为 `0.9835`，PSNR 为 `40.39 dB`，SSIM 为 `0.9670`。

因此，单通道对数幅度表示和当前 SwinIR 对一个样本具有充分拟合能力。本实验只增加样本数，检验一个共享模型能否同时表示 16 个空间分散样本。

## 实验契约

- 使用与此前复数 16 样本实验相同的锚点和确定性最远点采样；
- 16 个 512×512 patch 在原大图坐标中互不重叠；
- 每对样本独立计算 Echo RMS，并同时缩放该对 Echo/Image；
- 表示、模型、Charbonnier 损失、Adam、学习率和判定门槛与 E001 相同；
- 从随机初始化训练，不加载 E001 单样本权重；
- physical batch size 为 1，每 16 步覆盖全部样本一次；
- 每 1600 步评估全部 16 个样本；
- 只有 raw 模型的 16 个样本全部通过，并连续出现三次，实验才通过。

## 训练预算

E001 在 3800 次单样本更新时通过。因此本实验默认使用 `64000` 步，即每个样本约 4000 次更新。该预算略高于 E001，避免仅因每样本更新次数不足得出失败结论。

## 输出

- `selected_samples.json`：选择方法、坐标、SHA-256 和样本顺序；
- `metrics.jsonl`：每次评估的全部逐样本指标和聚合指标；
- `checkpoints/`：best、latest、final 和中断检查点；
- `figures/`、`predictions/`：锚点与当前 worst-RMSE 样本；
- `report.json`：基线、最终结果、最差 RMSE 和实验状态。

## 结果解释

- `16/16 passed`：排除相位后，当前模型可以统一记忆小规模幅度恢复映射；下一步扩大样本规模；
- 明显高于复数实验的 `12/16` 但未到 `16/16`：相位冲突是重要因素，但并非唯一因素；
- 仍稳定停在约 `12/16`：主要瓶颈更可能是共享局部网络容量、内容条件冲突或缺少大范围上下文；
- 多数样本失败：先核查逐样本 baseline、选择清单和幅度表示，不直接扩大规模。

无论结果如何，本实验仍只证明单一 parent scene 内的幅度拟合能力，不能证明跨场景泛化或复数 SAR 重聚焦。
