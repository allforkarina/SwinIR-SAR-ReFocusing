# E006：D001 共享复数频域滤波器可恢复性诊断

> 日期：2026-08-23
>
> 状态：已完成，D001共享空间不变滤波假设被否定
>
> 前置实验：[E005 能量保持幅度恢复](005-d002-energy-preserving-magnitude.md)

## 实验问题

E004/E005的人工审查证明，幅度SwinIR主要学习低频亮度包络、降噪和能量重标定，没有
恢复聚焦后的高频结构。E006停止训练神经网络，直接检验最简单的复数物理假设：

> Scene4各位置的粗成像Echo到聚焦Image，能否由同一个空间不变复数卷积描述？

若答案为是，映射可写成频域逐点复乘，后续模型应预测或微调可解释的复数传递函数；若
答案为否，则需要继续区分空间变相位/几何校正与局部patch信息不足。

## 数据与隔离

沿用E004/E005的固定空间划分：

| split | 数量 | 用途 |
| --- | ---: | --- |
| train | 15714 | 仅用于估计滤波器 |
| guard | 520 | 完全不用 |
| validation | 441 | 仅用于最终评价与人工审查 |

训练patch高度重叠，不能全部当成独立观测。脚本先在train中选择起始坐标间隔至少512
像素的候选，再均匀保留最多256个，避免重叠样本让一致性显得虚高。所有输入和标签继续
使用当前Echo的RMS共同缩放。

## 估计方法

对每个fit样本计算正交归一化二维FFT：

```text
X_i = FFT2(Echo_i / RMS(Echo_i))
Y_i = FFT2(Image_i / RMS(Echo_i))
```

共享复数Wiener/岭回归滤波器为：

```text
Sxx = sum_i |X_i|^2
Syx = sum_i Y_i * conj(X_i)
H   = Syx / (Sxx + 1e-3 * mean(Sxx))
prediction = IFFT2(H * FFT2(Echo))
```

同时估计一个训练集固定复数增益，作为“只调亮度和全局相位”的更弱基线。岭参数在
运行前固定，不使用validation标签选择。

## 传递一致性

fit样本的逐频率交叉谱一致性定义为：

```text
C = |sum_i Y_i conj(X_i)|^2 / (sum_i |X_i|^2 * sum_i |Y_i|^2)
```

`C`接近1表示不同patch在该频率共享稳定的复数映射；接近0表示相位或幅度关系随样本
变化。报告均值、中位数、能量加权均值，以及高于0.5/0.9的频率比例。

## 验证指标与门槛

441个validation patch同时比较：Echo identity、固定复数增益、共享频域滤波器。除复数
RMSE、coherence、幅度相关、PSNR和SSIM外，新增：

- 对数幅度梯度相关性；
- 梯度能量ratio；
- 半径0.25 Nyquist以上的高频能量ratio；
- 12个极端与空间分散样本的人工审查。

共享滤波假设只有同时满足以下预注册检查才获得“指标支持”：

1. 复数RMSE相对Echo和固定增益的胜率分别至少75%和60%；
2. mean complex coherence相对Echo至少提高0.02；
3. mean log SSIM和边缘相关相对Echo分别至少提高0.05；
4. 边缘相关相对固定增益至少提高0.02；
5. 高频能量ratio中位数位于0.75～1.25；
6. fit频域一致性能量加权均值至少0.50；
7. 人工图像显示真实边缘或点散射收缩，而非噪声锐化。

第7项由人工审查决定，因此脚本状态只使用`metric_supported`，不会自动宣称重聚焦成功。

## 决策规则

- 指标和人工审查都支持：共享复数去卷积成立，下一步实现受约束复数滤波模块；
- 一致性低且滤波无效：拒绝共享空间不变滤波，下一步审计坐标依赖相位/重采样；
- 一致性高但验证无效：检查方向、边界、FFT shift和patch裁切契约；
- 高频指标改善但图像伪锐化：仍判失败，不进入神经网络训练；
- 所有局部复数方法失败：回到完整场景或更大上下文，不再增加局部模型容量。

## 服务器结果（2026-08-24）

E006在256个空间分散的train patch上估计共享滤波器，并在全部441个validation patch
上得到：

| 结果 | Echo | 固定复数增益 | 共享滤波器 |
| --- | ---: | ---: | ---: |
| mean complex RMSE | 1.0303 | 0.7490 | 0.7506 |
| mean complex coherence | 0.00663 | 0.00663 | 0.00468 |
| mean log SSIM | 0.05474 | 0.00077 | 0.02405 |
| mean edge correlation | 0.00476 | 0.00000 | 0.00608 |
| median高频能量ratio | — | — | 0.3998 |

共享滤波器相对Echo的RMSE胜率为100%，但相对固定增益的胜率为0%。这说明RMSE下降
来自整体缩幅/趋零，不是共享滤波恢复了结构。滤波器还使coherence和SSIM低于Echo，且
仅保留约40%的目标高频能量。

更关键的是，训练样本逐频率传递一致性的能量加权均值只有0.00420，中位数0.00291，
没有任何频率达到0.5。这不是“共享滤波器容量略小”，而是不同patch之间不存在稳定的
共享复数传递函数。因此不进入共享滤波网络或更大SwinIR，下一步改为E007逐样本相位
oracle，区分低阶相位不足与“仅相位补偿本身不足”。
