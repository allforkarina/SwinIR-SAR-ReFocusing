# E003：D002-B2-A 16 样本训练预算扩展

> 日期：2026-08-19～2026-08-20
>
> 状态：实验通过
>
> 前置实验：[E002 16 样本联合对数幅度过拟合](002-d002-b2a-joint-16-magnitude-overfit.md)

## 决策依据

E002 在 64000 步时没有达到严格通过标准，但也没有出现少数异常样本或输出塌缩：

- 16 个样本的 normalized log RMSE 集中在 `0.1158～0.1559`；
- correlation 为 `0.9481～0.9829`；
- magnitude RMS ratio 为 `0.9894～1.0623`；
- SSIM 为 `0.9150～0.9525`；
- 最后 8000 步的整体趋势仍在改善，尚无稳定平台。

单样本在 3800 次更新时通过，而 E002 的 64000 步等于每个样本约 4000 次更新。相近的样本表现和仍在下降的损失说明，共享模型的优化速度明显慢于单样本，当前证据不足以归因于模型容量或输入信息缺失。

## 唯一实验变量

从 E002 的 `best.pt`（step 62400）继续训练，将总步数从 `64000` 增加到 `128000`。以下项目全部保持不变：

- 16 个样本及顺序；
- 单通道共享 Echo RMS 对数幅度表示；
- SwinIR 参数量和随机状态；
- Adam 优化器及其状态；
- 学习率 `2e-4`；
- Charbonnier 损失；
- EMA、评估间隔、保存间隔和通过门槛。

因此该实验只回答：E002 未通过是否主要由训练预算不足导致。

## 安全恢复契约

续训必须显式使用 `--allow-step-extension`。脚本执行顺序为：

1. 读取原 `resolved_config.json`；
2. 验证新旧配置只有 `optimization.max_steps` 不同且新值更大；
3. 使用旧配置严格恢复模型、优化器、调度器、scaler 和 RNG；
4. 恢复成功后先原子保存新契约的 `extension_start.pt` 和 `latest.pt`；
5. 最后把 `resolved_config.json` 更新为新总步数；
6. 后续 checkpoint 继续保存新的总步数契约。

任何学习率、模型、损失、样本指纹、采样或评估配置变化都会拒绝恢复，避免把多个变量混入本实验。

## 结果解释

- 达到连续三次 `16/16`：E002 的主要限制是共享训练收敛变慢；
- 指标继续改善但仍未通过：进入低学习率收敛实验，而不是继续无限增加步数；
- 很快形成稳定平台：再测试输入特征 B2-B 或更大上下文/容量；
- 指标明显退化：比较 `best.pt` 与续训 checkpoint，保留原最佳结果并停止本路线。

## 实验结果

检查点从 step `62400` 成功恢复，脚本按严格契约把总训练预算从 `64000`
扩展到 `128000`。训练没有用满预算：模型在 step `110400` 达到连续三次
`16/16`，触发提前通过。

关键过程如下：

- step `64000`：`0/16`，最差 normalized log RMSE 为 `0.1559`；
- step `92800`：首次出现 `16/16`，但下一次评估没有保持；
- step `104000`：再次出现 `16/16`；
- step `107200`、`108800`、`110400`：连续三次 `16/16`，实验通过。

最终 raw 模型的集合级最差指标为：

| 指标 | step 110400 |
| --- | ---: |
| worst normalized log RMSE | `0.0790` |
| minimum log-magnitude correlation | `0.9833` |
| magnitude RMS ratio range | `0.9641～0.9926` |
| minimum PSNR | `31.49 dB` |
| minimum SSIM | `0.9798` |

相对于 step `64000`，最差 RMSE 下降约 `49.3%`。这说明 E002 的失败主要是共享
模型收敛速度较慢和训练预算不足，而不是已经证实的模型容量不足、样本互相冲突或
局部输入信息不足。

## 结论边界与下一步

本实验只证明一个 SwinIR 可以同时记忆同一 parent scene 内 16 对局部对数幅度映射。
它排除了“增加到 16 对后模型必然无法拟合”的假设，但不证明模型能恢复未见 patch，
更不证明跨场景泛化或复数 SAR 重聚焦。

下一项实验不再继续增加这 16 个样本的训练步数，也不立即扩大模型。应固定当前
`512→512` 幅度基线，建立具有空间隔离带的同场景 train/validation split，先检验
未见区域上的经验恢复能力；若该基线泛化失败，再进入更大上下文输入的消融实验。
